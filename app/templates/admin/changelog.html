29 May 2026 Engine

SymPy Math Expression Checker

Fill-in-the-blank answers now support symbolic math equivalence checking via SymPy. Students can type mathematically equivalent expressions (e.g., 1+x instead of x+1) and get credit automatically.

How It Works

  • String match runs first (fast, handles non-math answers like “local maximum”)
  • If string match fails and the answer looks mathematical, SymPy parses both student and correct answer
  • Three-tier equivalence check: algebraic simplification → trig simplification → numerical evaluation
  • If SymPy can’t parse or times out, falls back to the original string match result

Supported Equivalences

  • Algebraic: 2(x+3) = 2x+6, x+1 = 1+x
  • Fractions: 1/2 = 0.5
  • Trig identities: sec²x = 1+tan²x
  • Constant of integration: x²/2+C matches x²/2+7
  • Unicode: π = pi, ∞ = infinity
  • Implicit multiplication: 2x parsed as 2*x

Technical

  • New module: app/utils/math_normalize.py
  • LRU cache (512 entries) on parsed expressions to avoid re-parsing
  • 2-second timeout on simplification to prevent slow expressions from blocking
  • Heuristic classifier skips non-math text (descriptive answers, units)
  • 15 unit tests covering numeric, algebraic, trig, Unicode, and rejection cases

27 May 2026 Architecture

4-Level Content Hierarchy

Complete redesign of the content architecture from 3 levels (Subject → Topic → Concept) to 4 levels (Subject → Course → Topic → Concept). Courses like "AP Calculus AB" are now properly modeled as courses within a subject, with topics like "Limits and Continuity" containing individual concepts. Concepts remain standalone, reusable building blocks linked via a many-to-many relationship.

New 4-Level Hierarchy

  • Subject (e.g., Mathematics) → Course (e.g., AP Calculus AB) → Topic (e.g., Limits & Continuity) → Concept (e.g., The Squeeze Theorem)
  • New Course model inserted between Subject and Topic, with tagline, course_type, course_info JSON, and difficulty_level
  • Subjects are now pure categories (Math, Physics, etc.) — course-specific fields moved to the Course model
  • Topics belong to a Course and represent units/chapters within that course
  • Concepts are standalone entities with globally unique slugs, linked to Topics via TopicConcept many-to-many table
  • Same concept can appear in multiple topics across different courses — created once, linked everywhere

4-Level URL Structure

  • Subject catalog: /subjects/
  • Course list: /subjects/<subject> — all courses within a subject
  • Course detail: /subjects/<subject>/<course> — rich landing page with topics, skills, exam info
  • Topic detail: /subjects/<subject>/<course>/<topic> — concept list with progress
  • Concept detail: /subjects/<subject>/<course>/<topic>/<concept>
  • Practice: /subjects/<subject>/<course>/<topic>/<concept>/practice/
  • Breadcrumbs updated to show full 4–5 level path on every page

Course Detail Pages

  • New course_overview.html template — rich landing page for each course
  • Hero header with subject icon, course name, tagline, course type badge, and quick stats
  • Sticky in-page navigation with scroll-tracking active state
  • Optional sections powered by course_info JSON: introduction, skills, prerequisites, exam structure, official links
  • Progress overview for logged-in users (overall completion bar)
  • Topic cards with concept counts, estimated time, per-topic progress bars
  • CTA footer (sign up / continue learning)

Reusable Concepts

  • Concepts are standalone entities with globally unique slugs
  • TopicConcept association table links concepts to topics with independent display_order
  • Same concept (e.g., "Solving Linear Equations") can appear in SAT Math, Algebra 1, and Grade 6 Math
  • Updating a concept's content, resources, or problems updates it everywhere it appears
  • Student progress is shared across courses — mastering a concept in one course reflects in all others
  • New concept metadata: subject_area, difficulty, tags

4-Level Resources

  • Resources can now be attached at concept, topic, course, or subject level
  • New course_id and concept_id FKs on Resource model
  • Concept-level resources are portable — they travel with the concept to every course it's linked to
  • Course-level resources appear on the course detail page
